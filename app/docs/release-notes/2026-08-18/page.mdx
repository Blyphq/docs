## @blyp/core v0.1.26

### Highlights

- Added `@blyp/core/farmjs` with the typed `blypPlugin()` factory and request-aware `logger`.
- Added request logging, trace propagation, authentication and custom enrichment, structured-log suppression, database flushing, and Node/Bun lifecycle cleanup.
- Added curated Farm observability events plus privacy-safe browser hydration, navigation, error, and performance telemetry.
- Added Farm package exports, optional peer metadata, documentation, and PluginManager/client lifecycle coverage.

### Verification

The upstream release passed 400 tests, type-checking, package builds, and production dependency audits.
