## @blyp/core v0.1.24

### Highlights

- Added typed `blyp.config` authoring support.
- Added the SolidStart integration for request-scoped logging and client ingestion.

### Migration notes

Existing configurations remain valid. New projects can adopt the typed configuration helper for earlier validation and better editor completion.
