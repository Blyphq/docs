## @blyp/core v0.1.25

### Highlights

- Stabilized the Clerk, Better Auth, and WorkOS logging integrations.
- Added HTTP connector forwarding.
- Added the MongoDB database connector.

### Migration notes

Configure only one authentication provider for a logger instance, and install the peer package for each provider or connector that the application uses.
