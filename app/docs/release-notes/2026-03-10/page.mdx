## @blyp/core v0.1.0

### Highlights

- Added standalone and browser logging.
- Added Elysia, Hono, Express, Fastify, NestJS, Next.js, TanStack Start, SvelteKit, and Workers integrations.
- Added structured logging, file logging, TypeScript declarations, subpath exports, and automated npm publishing.

The package was initially published as `blyp-js`; later releases completed the move to `@blyp/core`.

[View the original release on GitHub](https://github.com/Blyphq/blyp/releases/tag/v0.1.0).
